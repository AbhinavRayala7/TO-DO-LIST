
# 📝 To-Do List Website

A simple and clean to-do list web application built using **HTML**, **CSS**, and **JavaScript**. Tasks can be added and removed easily. Perfect for learning and deploying to platforms like **Vercel** or **GitHub Pages**.

## 🚀 Features

- Add new tasks
- Remove tasks by clicking on them
- Responsive and clean UI

## 📦 Folder Structure

```
todo-list-site/
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🌐 Live Preview

You can deploy this site easily using:
- [Vercel](https://vercel.com)
- [GitHub Pages](https://pages.github.com)

## 📤 Deployment Instructions

### 🔸 Vercel
1. Go to [https://vercel.com](https://vercel.com)
2. Create a new project and import your GitHub repo or upload files manually
3. Click **Deploy**

### 🔸 GitHub Pages
1. Create a new GitHub repository
2. Upload all files from this project
3. Go to **Settings > Pages**
4. Set source to the **main** branch
5. Your site will be available at `https://yourusername.github.io/repo-name`
